## 2. Workflow ที่คนส่วนใหญ่ใช้

```
รูปสินค้าจริง (จากหน้าร้าน/ถ่ายเอง)
   │
   ├─▶ Nano Banana (Gemini) : วางสินค้าในฉาก / ให้นางแบบ AI ถือ / ทำเฟรมแรก-เฟรมสุดท้าย
   │
   ├─▶ ChatGPT / Gemini / Claude : ส่งรูป + ข้อมูลสินค้า ให้ช่วยเขียนพรอมท์วิดีโอ
   │
   ├─▶ Veo 3 / 3.1 ใน Google Flow  (ทางเลือก: Kling, Hailuo, Sora ฯลฯ)
   │      ใช้ "Ingredients to video" (อัปรูปอ้างอิง) หรือ "First & Last frame"
   │
   ├─▶ CapCut : ต่อหลายช็อต 8 วิ → 15–60 วิ, ใส่ซับ/ข้อความ, เสียง
   │
   └─▶ Shopee Video : แนบลิงก์ Affiliate (ปักตะกร้า) + เปิดป้าย AI-generated
```

- ความยาวที่แนะนำบน Shopee Video: **15–60 วินาที** ([Lemon8 @dear.wow64](https://www.lemon8-app.com/@dear.wow64/7533323954690195984?region=us)); Veo เจนได้ทีละ ~8 วิ เลยต้องต่อหลายช็อต
- การปักตะกร้า: คัดลอกลิงก์สินค้าจาก Affiliate → วางในช่อง URL สินค้าของคลิป → กำหนดตำแหน่ง/ช่วงเวลาที่ไอคอนตะกร้าแสดง ([ข่าวสด](https://www.khaosod.co.th/sentangsedtee/featured/article_318967))
- เลือกสินค้า: ขายดี รีวิวดี คอมสูง, ของ "แก้ปัญหาเฉพาะหน้า" (พัดลมพกพา ของแต่งบ้าน สกินแคร์เห็นผลชัด), ราคา 99–399 บาท

## 3. รูปแบบคลิปที่นิยม

1. **UGC นางแบบ/นายแบบ AI พูดไทย ถือสินค้า** — แบบรีวิวหน้ากล้อง มือถือแนวตั้ง (ใช้ "ตัวละครคนเดิม" ข้ามคลิปเพื่อสร้างภาพจำช่อง)
2. **การ์ตูน 3D / ตัวละครน่ารักขายสินค้า** — มีคลิปสอนใน TikTok เยอะ (เข้ากับช่องแนวตัวการ์ตูนอย่าง Bear Friends)
3. **Cinematic product shot** — macro, หมุนสินค้า, dolly-in, แสง rim light, ไม่มีคน
4. **Demo แก้ปัญหา (Problem → Product → Proof)** — เช่น โต๊ะรก → วางที่จัดระเบียบ → เรียบร้อย
5. **ช็อตสั้น 6–8 วิ หลายคลิปต่อสินค้า** — เน้นปริมาณ ทดสอบหลายแบบ

## 4. โครงพรอมท์ที่เจอ (หลักการ)

### 4.1 สูตรทางการของ Google (Veo 3.1)
**[Cinematography] + [Subject] + [Action] + [Context] + [Style & Ambiance]**
- บทพูด → ใส่ในเครื่องหมายคำพูด: `A woman says, "..."`
- เสียงเอฟเฟกต์ → `SFX: ...`
- เสียงบรรยากาศ → `Ambient noise: ...`
- สิ่งที่ไม่อยากได้ → เขียนเชิงบวก เช่น "a clean table with nothing else on it" แทน "no clutter"
- Ingredients to video: อัปรูปสินค้า/ตัวละคร/ฉาก แล้วอ้างถึงใน prompt ("Using the provided images of ...")
- First & Last frame: ให้รูปเริ่ม-จบ แล้วบรรยายการเคลื่อนไหวระหว่างกลาง

### 4.2 เทมเพลต UGC 13 ช่อง (cliprise / GitHub)
1. ความยาว + แนวตั้ง + สินค้า 2. กลุ่มเป้าหมาย 3. บทบาทคนในคลิป 4. การเปิดเผยว่าเป็นโฆษณา 5. **Hook** (2–3 วิแรก)
6. ปัญหา/ความต้องการ 7. **Product moment** (สินค้าโผล่ตอนไหน) 8. **Demo/Proof** (โชว์ให้เห็น ไม่ใช่แค่พูดอ้าง)
9. กล้อง 10. ฉาก 11. เสียง 12. **CTA** สั้นๆ 13. **Restrictions** (ห้ามอ้างเกินจริง, มือบิดเบี้ยว, ฉลากเพี้ยน, รีวิวปลอม)

### 4.3 ลำดับบล็อกจาก UGC Maker (Kling)
คนในคลิป + vibe → กล้อง/ความสมจริง → การกระทำ/เดโม → บทพูดสั้น → ข้อความบนจอ → CTA เดียว

### 4.4 ทริคที่คนแชร์กัน
- ขอ **vertical 9:16** ชัดๆ, วัตถุอยู่กลางเฟรม, **สินค้าต้องโผล่เร็ว**
- **1 คลิป = 1 การเคลื่อนไหวหลัก** อย่าสั่งหลายอย่างพร้อมกัน
- ใส่ช็อตพื้นหลังเรียบหนึ่งช็อต ช่วยให้ต่อ transition เนียน
- ระบุภาษาพูด/lip-sync เป็น **ภาษาไทย** ชัดเจน (เช่น "speaks in Thai") — Veo 3.1 บางทีแต่งบทพูดเอง ถ้าไม่ล็อกบทไว้
- ข้อความ/ป้ายภาษาไทยในฉากมักเพี้ยน (มีรีวิวเจอไทยปนจีน) → เลี่ยงตัวหนังสือในฉาก ไปใส่ซับทีหลังใน CapCut แทน
- ตรวจ **โลโก้ ฉลาก สี ขนาด** ให้ตรงสินค้าจริงทุกครั้ง

## 5. เทมเพลตพรอมท์ (สังเคราะห์ — พร้อมแก้ใช้)

### 5.1 UGC รีวิวพูดไทย 8 วินาที (Veo 3.1 + รูปสินค้าเป็น ingredient)
```
Vertical 9:16, 8 seconds, smartphone UGC style.
Using the provided product image of [ชื่อสินค้า], keep its exact shape, color, size and label.
Medium close-up, handheld, slight natural shake. A friendly Thai woman in her 20s, casual home outfit,
in a bright bedroom with soft morning daylight.
0–2s: she holds the product up close to the camera and says in Thai, "[ฮุก เช่น ใครผมชี้ฟูตอนเช้าต้องดูอันนี้]"
2–6s: she demonstrates [การใช้งานจริง 1 อย่าง], the result is clearly visible.
6–8s: she smiles and says in Thai, "[CTA เช่น กดตะกร้าด้านล่างได้เลย]"
Audio: natural room tone, her voice clear, lip-sync in Thai. No background music.
The product stays fully visible and undistorted; the frame contains only this one product; hands look natural.
```

### 5.2 ตัวการ์ตูนขายของ (แนวช่อง Bear Friends)
```
Vertical 9:16, 8 seconds, 3D animated Pixar-like style.
Using the provided character image of [ชื่อตัวละคร หมี] and the product image of [สินค้า].
Medium shot. The cute bear sits at a tidy wooden table in a cozy pastel room.
The bear picks up the [สินค้า] with both paws, looks surprised and happy, and says in Thai in a cheerful
childlike voice, "[บทพูดสั้น 1 ประโยค]".
Camera slowly pushes in to the product at the end.
SFX: a soft "pop" when the product appears. Ambient noise: light, playful room tone.
The product keeps its real colors, shape and label exactly as in the reference image.
```

### 5.3 Cinematic product shot (ไม่มีคน)
```
Vertical 9:16, 8 seconds. Macro product hero shot of [สินค้า] standing on [พื้นผิว เช่น dark slate].
Slow 180-degree orbit around the product, soft rim light, shallow depth of field, gentle reflections,
light atmospheric haze, clean commercial color grade.
SFX: subtle whoosh at the start. The background stays plain and empty except for the product.
```

### 5.4 แบบ JSON (บางคนชอบใช้กับ Veo/Flow — ไม่มีมาตรฐานตายตัว)
```json
{
  "format": { "aspect_ratio": "9:16", "duration_sec": 8, "style": "smartphone UGC, handheld" },
  "product": { "name": "[สินค้า]", "reference_image": "provided", "must_match": ["color", "shape", "size", "label"] },
  "character": { "description": "Thai woman, 20s, casual outfit, friendly", "language": "Thai" },
  "setting": "bright bedroom, soft morning daylight",
  "shots": [
    { "time": "0-2s", "camera": "close-up", "action": "holds product to camera", "dialogue": "[ฮุก]" },
    { "time": "2-6s", "camera": "medium close-up", "action": "[เดโม 1 อย่าง]", "dialogue": "" },
    { "time": "6-8s", "camera": "medium shot", "action": "smiles", "dialogue": "[CTA]" }
  ],
  "audio": { "music": "none", "ambient": "natural room tone" },
  "constraints": ["product undistorted and fully visible", "natural hands", "no on-screen text"]
}
```

### 5.5 Meta-prompt ให้ ChatGPT/Gemini/Claude เขียนพรอมท์ให้ (วิธีที่คนไทยใช้เยอะสุด)
```
คุณคือผู้เชี่ยวชาญเขียนพรอมท์ Veo 3.1 สำหรับคลิปขายของ Shopee Affiliate
ข้อมูลสินค้า: [ชื่อ, ราคา, จุดเด่น 3 ข้อ, ปัญหาที่แก้]  (แนบรูปสินค้า)
กลุ่มเป้าหมาย: [...]
สไตล์: [UGC คนจริง / การ์ตูน 3D / cinematic]
ให้เขียนพรอมท์ภาษาอังกฤษ 3 ช็อต ช็อตละ 8 วินาที แนวตั้ง 9:16 โดย:
- ใช้สูตร Cinematography + Subject + Action + Context + Style
- บทพูดเป็นภาษาไทย อยู่ในเครื่องหมายคำพูด ไม่เกิน 1 ประโยคต่อช็อต
- ช็อตแรกต้องมีฮุกใน 2 วินาทีแรก และเห็นสินค้าทันที
- มีช็อตเดโมให้เห็นผลจริง ห้ามอ้างสรรพคุณเกินจริง/ทางการแพทย์
- สินค้าต้องเหมือนรูปอ้างอิงทุกอย่าง (สี ขนาด ฉลาก)
- ปิดด้วย CTA สั้นๆ ชวนกดตะกร้า
และเขียนแคปชันไทย + แฮชแท็ก (มี #AIgenerated) ให้ด้วย
```

## 6. กฎ / ความเสี่ยง (สำคัญมาก)

- **Shopee (สิงคโปร์) – แนวทาง AIGC บน Shopee Video มีผล 1 ส.ค. 2026:** ต้องเปิดปุ่ม **"AI-generated Inform"** ก่อนโพสต์ ไม่เปิด = **หัก 3 คะแนน + ลบคลิป**; ห้ามเพิ่ม/เปลี่ยนคุณสมบัติสินค้าที่ไม่มีจริง (สี ขนาด วัสดุ รูปทรง) ([Shopee SG Help](https://help.shopee.sg/portal/10/article/201777))
- **Shopee (มาเลเซีย):** คอนเทนต์ AI ทุกชิ้นต้องติดป้าย, ระบบอาจติดป้ายให้อัตโนมัติ; บทลงโทษไล่ระดับ: หักคะแนน → **ลดการมองเห็น** → ลบคลิป → แบน Shopee Video ชั่วคราว/ถาวร ([Shopee MY Seller Edu](https://seller.shopee.com.my/edu/article/27547))
- **BigSeller:** ถ้าระบบติดป้าย AI ให้เอง จะ**เอาออกไม่ได้** → ติดป้ายเองตั้งแต่แรกดีกว่า ([BigSeller](https://www.bigseller.pro/blog/articleDetails/4649/shopee-video-AI-2026.htm))
- **ไทย – สคบ.** ออกแนวทางโฆษณาที่ใช้ AI สร้างเนื้อหาที่อาจทำให้ผู้บริโภคเข้าใจผิด ภายใต้ พ.ร.บ.คุ้มครองผู้บริโภค ([Tilleke & Gibbins](https://www.tilleke.com/insights/thailands-advertising-guidelines-targeting-ai-generated-content/3/))
- **ครีเอเตอร์ไทยเตือน:** ความเสี่ยงจริงคือ "รีวิวปลอมทำเหมือนใช้จริง", ปลอมเสียง/หน้าคนจริง, ใช้ภาพเด็ก, และ **บอท/ระบบอัตโนมัติปั่นยอด** มากกว่าคำว่า AI เอง; แนะนำใช้เสียงตัวเองหรือผสมของจริงกับ AI
- **เทรนด์ 2026:** "AI-Content Flood" คนเริ่มเบื่อคลิป AI ที่ดูดีแต่ไม่จริงใจ ความน่าเชื่อถือคือจุดต่าง ([Everyday Marketing](https://everydaymarketing.co/marketing-trends/check-out-5-affiliate-marketing-trends-2026-in-sincerity-in-addition-to-your-assets-you-also/))
